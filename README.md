# EcoDescarte

Site de conscientização sobre o descarte correto de resíduos, desenvolvido como projeto da disciplina de Projeto Integrador do curso Técnico em Informática do IFTO Campus Paraíso.

🌐 **Acesse o site:** https://eco.pso-to.srv.br/
📸 **Instagram:** @ecodescarte.pso

## Sobre o projeto

O EcoDescarte foi criado em 2025 com o objetivo de informar e conscientizar as pessoas sobre a importância de descartar corretamente diferentes tipos de materiais, contribuindo para a preservação do meio ambiente.

O projeto foi proposto e orientado pela professora Thatiane Rosa e desenvolvido pelos alunos da turma como atividade prática da disciplina, aplicando na prática o que foi aprendido ao longo do curso.

## Como executar

### Online

O site está hospedado em um link disponibilizado pela prefeitura de Paraíso do Tocantins e pode ser acessado diretamente:

👉 https://eco.pso-to.srv.br/

### Localmente

**Pré-requisitos**

- Um navegador atualizado (Chrome, Firefox, Edge etc.)
- [Git](https://git-scm.com/) instalado (opcional, só para clonar o repositório)
- [VS Code](https://code.visualstudio.com/) com a extensão **Live Server** (opcional, recomendado)

**Passo a passo**

1. Clone o repositório:

   ```bash
   git clone https://github.com/natalialambert/ecodescarte.git
   ```

   Ou baixe o projeto em **Code → Download ZIP** e extraia a pasta.

2. Entre na pasta do projeto:

   ```bash
   cd ecodescarte
   ```

3. Abra o site de uma das formas abaixo:

   - **Direto no navegador:** dê dois cliques no arquivo `index.html`.
   - **Com o Live Server (recomendado):** abra a pasta no VS Code, clique com o botão direito no `index.html` e escolha **Open with Live Server**.

O site abrirá no navegador e não precisa de instalação de dependências nem de configuração adicional.
